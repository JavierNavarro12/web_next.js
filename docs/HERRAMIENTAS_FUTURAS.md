# 🛠️ Herramientas para Añadir en el Futuro

## 📊 Comparador de IAs

**IAs y plataformas que ayudan a comparar modelos o hacer benchmarks.**

- **Chatbot Arena (LMSYS)** – Comparador interactivo de LLMs
- **Hugging Face Leaderboard** – Ranking de modelos de texto, visión y multimodales
- **Papers with Code** – Comparativas de modelos por benchmarks académicos
- **Arena Hard** – Evaluaciones de prompts difíciles entre GPT, Claude y otros
- **OpenLLM Leaderboard** – Para modelos open source como LLaMA, Mistral, Falcon
- **Zeno AI** – Herramienta para evaluar y comparar outputs de IAs

---

## 💰 Calculadora de costos

**IAs y recursos que permiten calcular precios y consumo de IA.**

- **OpenAI Pricing Calculator** – Estimador oficial para ChatGPT y GPT API
- **Anthropic Token Calculator** – Para Claude (tokens y costos)
- **Google AI Studio Token Estimator** – Para Gemini
- **Replicate Cost Calculator** – Para modelos open source en la nube
- **RunPod Pricing Estimator** – Para inferencia y entrenamiento de modelos
- **Suno Cost Calculator** (no oficial, comunitaria) – Estima costos de música IA
- **ElevenLabs Cost Estimator** – Para conversión de voz y minutos de audio

---

## ✍️ Generador de Prompts

**IAs y herramientas enfocadas en prompt engineering y creación de prompts de calidad.**

- **FlowGPT** – Comunidad con miles de prompts listos para usar
- **PromptPerfect** – Optimización automática de prompts para ChatGPT, Claude, MidJourney, etc.
- **AIPRM** – Extensión para Chrome que ofrece prompts organizados por categorías
- **PromptBase** – Marketplace de prompts premium
- **PromptHero** – Biblioteca visual de prompts para MidJourney, DALL·E y Stable Diffusion
- **Jasper Prompt Generator** – Para marketing y redacción
- **ChatX Prompt Generator** – IA que crea prompts a partir de objetivos del usuario

---

## ✅ Evaluador de Calidad

**IAs y plataformas para medir, evaluar y auditar resultados de IA.**

- **TruLens** – Evalúa la calidad de respuestas de LLMs
- **Helicone** – Métricas y feedback sobre rendimiento de modelos
- **PromptLayer** – Análisis de prompts y outputs en producción
- **Arize AI** – Evaluación de precisión y sesgo en modelos de IA
- **Humanloop** – Plataforma para testing de prompts y evaluación de outputs
- **LM Evaluation Harness** – Framework open source de evaluación de LLMs
- **Genei Evaluator** – Evalúa resúmenes y respuestas de IAs en base a criterios de claridad y precisión
