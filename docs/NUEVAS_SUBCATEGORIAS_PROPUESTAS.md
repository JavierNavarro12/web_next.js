## 13. Propuesta de taxonomía → Sistema de etiquetas (tags)

- **Por sector**: salud, finanzas, legal, educación, eCommerce, geoespacial, gaming, etc.
- **Por capacidad**: generación de texto/imagen/audio/video, STT, TTS, RAG, agentes, razonamiento, datos sintéticos, etiquetado, OCR, visión, etc.
- **Por producto**: SaaS, framework, modelo, SDK, servicio cloud, on‑device.
- **Por cumplimiento**: privacidad, anonimización, seguridad/Trust & Safety.
- **Por pricing**: free, freemium, paid.

👉 **Motivo:** Mantener categorías y subcategorías para navegación, y usar tags para evitar duplicados y mejorar el filtrado (una IA puede vivir en varias vistas sin inconsistencias).
